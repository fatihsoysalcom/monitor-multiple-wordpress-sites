# Monitor Multiple WordPress Sites

This Python script demonstrates how to efficiently monitor the status and WordPress version of multiple websites using a custom script. It takes a list of URLs, attempts to fetch their homepages, extracts the WordPress version from the generator meta tag, and reports the HTTP status code for each site. This illustrates a simple approach to centralizing routine checks for many WordPress installations.

## Language

`python`

## How to Run

Save the code as `monitor_wp_sites.py`. Open your terminal or command prompt, navigate to the directory where you saved the file, and run: `python monitor_wp_sites.py`
